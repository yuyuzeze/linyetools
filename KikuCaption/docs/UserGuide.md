# KikuCaption 用户指南（Windows 11）

面向普通用户的安装、使用与卸载说明。技术细节见其余 `docs/`。

## 1. 安装

1. 解压 `KikuCaption-<版本>-win-x64.zip` 到一个**用户可写目录**（如桌面或文档下的文件夹，**不要**放在
   `C:\Program Files`，否则默认输出目录不可写）。
2. 安装 **Python 3.13.x**（勾选「Add to PATH」）。
3. 在解压目录打开 PowerShell，运行一次性环境安装：
   ```powershell
   ./setup-python.ps1
   ```
   它创建 venv 并安装锁定依赖（不含模型）。
4. **FFmpeg**：包内 `tools/ffmpeg` 若已含 `ffmpeg.exe`/`ffprobe.exe` 即可；否则在 `appsettings.json` 设置
   `Recording:FFmpegPath` 指向本机 FFmpeg。FFmpeg 为 **GPL v3**，分发义务见 `THIRD_PARTY_NOTICES.md`。

## 2. 首次启动

- 双击 `KikuCaption.exe`。程序做环境预检并显示结果（通过/警告/阻断）。
- **模型首次下载**：首次识别会下载 faster-whisper `small` 模型（约 464 MB，**需联网一次**，有进度与磁盘提示）。
  下载完成后**可离线使用、不重复下载**。

## 3. 录制一场 Teams 会议

1. 选择**识别语言**：日本語(ja) 或 中文(zh)。
2. 选择**录制目标**：整个屏幕 或 指定窗口（可「刷新窗口」列表）。
3. （可选）在「日译中翻译」面板启用翻译并配置（见第 5 节）。
4. 点「开始录制和字幕」。程序统一走：预检 → 创建会话 → 系统声音捕获 → 录屏 → 实时识别 → 渐进字幕 → 右侧完整时间线 → SQLite 实时保存 →（可选）日译中。
   - 「会话状态」显示 空闲/预检中/启动中/运行中/停止中/已完成/已故障；「健康」显示运行正常/CPU 偏高/磁盘不足。
   - 若录屏不可用，会明确提示「仅字幕继续」，不静默降级。
5. 点「停止」安全停止：flush 字幕 → drain 存储 → 保留翻译待处理 → 结束录屏 → 导出全部字幕 → 完成会话。

## 4. 查看完整会议字幕时间线

- 右侧为**全程时间线**，保留本场从第一条到最后一条的全部 final 字幕（最早在上、最新在下）。
- 可从**第一条一直滚动到最后一条**（数千条流畅，UI 虚拟化）。
- **自动滚动**：位于底部时新字幕自动跟随；**向上查看历史时不会被拉回底部**，出现「有 N 条新字幕 ↓」提示，点击回到最新并恢复自动滚动；自行滚到底也恢复。
- 「清空显示」只清屏幕，**不删除**数据库或字幕文件；「加载最近会话」可从 SQLite 重开上一场。
- **字幕浮窗**：可显示/隐藏、调字号/透明度、鼠标穿透；翻译返回后在原文下方原地补中文（双行）。

## 5. 翻译 API 配置与密钥

见 [Translation.md](Translation.md) 与 [Security.md](Security.md)。要点：

- 面板填写 Endpoint（完整 HTTPS）、Model/Deployment、可选 API Version、认证模式（Bearer/ApiKeyHeader/None）与 Header 名。
- **API Key** 在 `PasswordBox` 输入并点「保存密钥」——以 **Windows DPAPI** 加密保存在本机
  `%LOCALAPPDATA%\KikuCaption\secrets`，**绝不**写入配置/日志/数据库，**不要**贴进代码或聊天。可「清除密钥」。
- 「测试连接」发送固定非敏感文本，不发送真实会议字幕。
- 只发送**日语 final 文本**；不发送音频、partial、视频。翻译失败保留原文、不影响录屏。

## 6. 输出文件

会话目录（默认 `<应用目录>\Meetings\<时间_会话id>\`，可在设置改为用户可写路径）：

```
meeting.mp4            # 录屏 + 系统声音（H.264 + AAC）
transcript.json        # 原文 + 译文（结构化）
transcript.txt         # 原文纯文本
transcript.srt         # 原文字幕
translation.srt        # 中文翻译字幕（有成功翻译时）
session.json           # 会话元数据与统计
```

## 7. 磁盘空间与隐私

- 开始前检查磁盘，录制中定期复查；不足时安全停止并保存字幕，**不自动删除**用户会议。
- 日志**不记录**字幕正文、翻译正文、PCM、窗口敏感标题、API Key。请遵守你公司的录制与数据政策。

## 8. 异常与恢复

- 录制中关闭应用会**确认**并安全停止（不强杀），保留 MP4 与字幕。
- 崩溃后重启会自动恢复未完成会话、重建字幕文件，并恢复未完成的翻译任务，不重复。
- MP4 若不完整会被**保留并标记**，不会被删除。

## 9. 常见错误

| 现象 | 处理 |
|---|---|
| 预检「输出目录不可写」 | 把应用移到用户可写目录，或在设置改 `Storage:OutputDirectory` |
| 预检「模型缺失」 | 首次运行联网下载；确认磁盘空间 |
| 「未找到 FFmpeg」 | 配置 `Recording:FFmpegPath` 或放入 `tools/ffmpeg` |
| 翻译「认证失败」 | 重新保存正确的 API Key / 认证模式（密钥不会显示） |
| 翻译「限流/服务不可用」 | 稍后自动重试；原文与录屏不受影响 |

## 10. 完整卸载

删除解压目录即卸载程序本体。**默认不会删除**你的数据；如需彻底清除，请**手动**删除：

- 会议文件：`<应用目录>\Meetings\`（或你设置的输出目录）
- 数据库：`<应用目录>\Meetings\kikucaption.db`（或对应目录）
- API 密钥（DPAPI 密文）：`%LOCALAPPDATA%\KikuCaption\secrets\`
- 用户设置：`%LOCALAPPDATA%\KikuCaption\settings.json`
- 日志：`<应用目录>\logs\`

以上均为用户数据，请自行确认后删除。
